# Payments ops

Ops tooling for the payments team: agent skills and the scripts they call. The service itself lives in `refund-api`.

## Skills

| Skill | What it does |
|---|---|
| `deploy` | Plans and applies a deploy of `refund-api` to staging or production |

Skills live in `.claude/skills/`. See `AGENTS.md` for the rules agents follow in this repo.
